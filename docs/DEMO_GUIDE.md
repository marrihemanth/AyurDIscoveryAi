# AyurDiscovery AI - Hackathon Demo Guide

## 🎯 Demo Overview

**AyurDiscovery AI** is a professional MERN stack multiagent AI system that bridges traditional Ayurvedic medicine with modern pharmaceutical research. This demo showcases an innovative approach to drug discovery by combining ancient wisdom with contemporary technology.

## 🚀 Live Demo Instructions

### Starting the Application

1. **Backend Server**
   ```bash
   cd server
   npm start
   ```
   ✅ Server runs on http://localhost:5000

2. **Frontend Application**
   ```bash
   cd client
   npm start
   ```
   ✅ App opens at http://localhost:3000

### Demo Flow

#### 1. Initial Dashboard View
- **Showcase**: Professional UI with Material-UI design
- **Highlight**: Multi-language header (English, Hindi, Telugu)
- **Features**: Clean, responsive layout with agent status panel

#### 2. Text Search Demonstration
**Example Query**: "turmeric anti-inflammatory properties"

**Steps**:
1. Enter query in search interface
2. Select "General" search type
3. Click "Search" button
4. **Watch**: Real-time agent processing
   - Coordinator Agent starts
   - Literature Agent processes
   - Compound Agent analyzes
   - Cross-Reference Agent validates
   - All agents complete with 100% progress

**Results**:
- Literature Analysis: References to Charaka Samhita
- Compound Analysis: Curcumin identification
- Cross-Reference: Modern research validation
- Confidence levels: 84%, 89%, 92%

#### 3. Telugu Voice Input Demo
**Steps**:
1. Switch to "Voice Input" section
2. Select "Telugu (తెలుగు)" language
3. Click "START VOICE INPUT"
4. **Simulated Recognition**: "వేప వైద్య లక్షణాలను విశ్లేషించండి"
   (Analyze neem medicinal properties)
5. **Watch**: Automatic search initiation

**Outcome**:
- Voice processing results at 90% confidence
- Automatic agent coordination
- Telugu text processing demonstration

#### 4. Agent Status Monitoring
**Showcase**:
- Real-time status updates (idle → processing → completed)
- Progress bars with percentage completion
- Color-coded status indicators
- Timestamp tracking for last updates
- Professional icons for each agent type

#### 5. Results Analysis
**Features**:
- Confidence-based result ranking
- Agent-specific categorization
- Detailed analysis information
- Professional result cards with progress indicators
- Multi-language support demonstration

## 🔧 Troubleshooting

### Common Demo Issues
1. **Port Conflicts**: Ensure ports 3000 and 5000 are available
2. **Network Issues**: Check localhost connectivity
3. **Browser Compatibility**: Use Chrome/Firefox for best experience
4. **Screen Resolution**: Demo optimized for 1920x1080

### Quick Fixes
- **Refresh Issues**: Clear browser cache
- **Loading Problems**: Restart both servers
- **UI Glitches**: Ensure all dependencies installed
